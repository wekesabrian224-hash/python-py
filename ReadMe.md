# Full Python Course Structure

A complete curriculum path from absolute beginner to job-ready, organized into modules. Each module lists core topics and a suggested mini-project to cement the skills before moving on.

---

## Module 1 — Python Fundamentals

- Installing Python, running scripts, using the REPL/IDE
- Variables, data types (int, float, str, bool)
- Type conversion (`int()`, `float()`, `str()`)
- Basic input/output (`input()`, `print()`, f-strings)
- Operators: arithmetic, comparison, logical, assignment
- Comments and code style (PEP 8 basics)

**Mini-project:** Simple calculator or unit converter.

---

## Module 2 — Control Flow

- `if`, `elif`, `else` statements
- Boolean logic and truthy/falsy values
- Nested conditionals
- `while` loops and infinite loop pitfalls
- `for` loops and `range()`
- `break`, `continue`, `pass`
- Loop patterns: accumulation, counting, searching

**Mini-project:** Number guessing game or a text-based quiz.

---

## Module 3 — Strings and Collections

- String methods, slicing, formatting
- Lists: creation, indexing, slicing, methods (`append`, `sort`, `pop`, etc.)
- Tuples and immutability
- Dictionaries: keys, values, methods, iteration
- Sets and set operations
- List comprehensions (and dict/set comprehensions)
- Nested data structures

**Mini-project:** Contact book or word-frequency counter.

---

## Module 4 — Functions

- Defining functions, parameters, return values
- Default, keyword, and variable-length arguments (`*args`, `**kwargs`)
- Scope: local vs global
- Lambda functions
- Recursion basics
- Docstrings and documenting functions

**Mini-project:** Library of reusable utility functions (e.g. validators, converters).

---

## Module 5 — Error Handling & Debugging

- Exceptions: `try`, `except`, `else`, `finally`
- Raising custom exceptions
- Common built-in exceptions (`ValueError`, `TypeError`, `KeyError`, etc.)
- Debugging techniques (print debugging, using a debugger)
- Input validation patterns

**Mini-project:** Robust input-validated form (e.g. age/email/phone checker).

---

## Module 6 — File Handling & Modules

- Reading/writing text files
- Working with CSV and JSON
- Context managers (`with` statement)
- Importing modules and packages
- Standard library highlights (`os`, `sys`, `datetime`, `random`, `math`)
- Creating your own modules

**Mini-project:** Expense tracker that saves/loads data from a file.

---

## Module 7 — Object-Oriented Programming (OOP)

- Classes and objects
- `__init__`, instance vs class attributes
- Methods, `self`
- Inheritance and polymorphism
- Encapsulation and property decorators
- Magic/dunder methods (`__str__`, `__repr__`, `__eq__`)
- Composition vs inheritance

**Mini-project:** Small RPG character system or a bank account simulator.

---

## Module 8 — Testing & Code Quality

- Writing unit tests (`unittest` or `pytest`)
- Test-driven development basics
- Linting and formatting tools (`flake8`, `black`)
- Version control with Git/GitHub fundamentals
- Virtual environments (`venv`) and dependency management (`pip`, `requirements.txt`)

**Mini-project:** Add a test suite to a previous mini-project.

---

## Module 9 — Working with Data

- `pandas` basics: DataFrames, reading CSV/Excel
- Data cleaning and transformation
- `matplotlib`/`seaborn` for basic visualization
- Working with APIs (`requests` library, JSON responses)
- Web scraping basics (`BeautifulSoup`)

**Mini-project:** Pull data from a public API and visualize it.

---

## Module 10 — Building Applications

- Command-line applications (`argparse`)
- Intro to web development: Flask or Django basics
- Building a simple REST API
- Connecting to a database (SQLite, then PostgreSQL)
- Environment variables and configuration

**Mini-project:** A small web app with a database-backed CRUD feature (e.g. a task tracker).

---

## Module 11 — Advanced Python

- Generators and iterators
- Decorators
- Context managers (custom `__enter__`/`__exit__`)
- Multithreading/multiprocessing basics
- Async programming (`asyncio`) overview
- Type hints and static typing (`mypy`)

**Mini-project:** Refactor an earlier project using decorators and generators.

---

## Module 12 — Capstone & Career Prep

- Full-stack capstone project (planning, building, deploying)
- Deploying an app (e.g. Vercel, Render, Heroku)
- Writing a technical README and documenting a project
- Building a portfolio (GitHub profile, personal site)
- Resume/interview prep: common Python & DSA interview questions
- Freelancing/job-search strategy

**Capstone project ideas:** Full-stack portfolio site, a job-board scraper + dashboard, or a small SaaS tool tied to a real problem (e.g. Kenya-market finance/utility tools).

---

## Suggested pacing

- **Weeks 1–3:** Modules 1–3 (fundamentals, control flow, collections)
- **Weeks 4–5:** Modules 4–5 (functions, error handling)
- **Weeks 6–7:** Modules 6–7 (files/modules, OOP)
- **Week 8:** Module 8 (testing & tooling)
- **Weeks 9–10:** Modules 9–10 (data & app-building)
- **Weeks 11–12:** Module 11 (advanced topics)
- **Weeks 13+:** Module 12 (capstone & career prep)

Adjust pacing based on prior experience — someone with a math/programming background (loops, conditionals, functions) can often compress Modules 1–4 significantly.
